# Burrow & Bellow V2

Original underground digging game. V1 stays at
`/mnt/tnas-john/Documents/Programs/DigDug Mame/BurrowAndBellow` and is not
edited from here. V1 is playable and thin: a caption on round 1, one saved
score, no demo, no surface flower row, and 16×16 text-grid sprites.

V2 is the research-first rebuild. The GameMaker project is
`BurrowAndBellowV2.yyp` in this folder. It compiles and runs in coder box 2.

Enter starts a round from the title. Arrow keys or WASD move and dig. Space
pumps. Escape pauses. The title lists five scores. The open strip above the
dirt shows one flower for each round, up to eight. A demo mode is not in
this build, and the sprites are still the first set.

Read `analysis/README.md` before changing the game. A pass file says what was
read, what was checked, and what is still open. The handoff for a new
session is `docs/NEXT-SESSION.md`.

The program images used for the checks stay on the TNAS, next to V1:

`/mnt/tnas-john/Documents/Programs/DigDug Mame/roms/`

Those chips are not part of this repository.
